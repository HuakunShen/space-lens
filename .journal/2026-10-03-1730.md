# 2026-10-03 17:30

## Core Decision/Topic

Fix DSH plugin embedded pairing and CORS / connection failure, mirroring the
transport fix established in Refyard (`c23335b`), and release `dsh-plugin-spacelens@0.1.2`.

## Problems Diagnosed

1. **Embedded transport escaping the renderer carrier**:
   - `apps/dsh/src/host.ts` originally redirected the embedded frame using an
     absolute URL in `?api=${origin}${directorySegment(canonical)}`.
   - In desktop environments (`dsh-app://app` custom scheme) or embedded
     cross-port contexts, sending fetches to an absolute HTTP address violates
     `connect-src 'self'`, escapes the desktop forwarder carrier, and triggers
     CORS preflight failures.
2. **Web SPA Base URL resolution**:
   - `apps/web/src/lib/workbench.svelte.ts` previously only considered URLs exactly
     matching `window.location.origin` as `sameOrigin`, breaking when given a
     root-relative path (e.g. `/space-lens/d/<encoded_dir>`).
3. **Loopback pairing ticket binding**:
   - `packages/host/src/auth.ts` strictly compared `record.origin !== input.origin`
     and consumed tickets immediately upon any mismatch, causing legitimate
     exchanges from another loopback spelling (`localhost` vs `127.0.0.1`) to fail.

## Key Changes Made

- **`packages/host/src/auth.ts`**:
  - Implemented `sameLoopbackService()` matching any loopback spelling (`127.0.0.1`,
    `localhost`, `[::1]`) on the same port at exchange time.
  - A refused origin probe no longer consumes the single-use pairing ticket, allowing
    the legitimate page to redeem it afterwards.
- **`apps/web/src/lib/base-url.ts` & `workbench.svelte.ts`**:
  - Extracted pure runtime `parseBaseUrl` and `normalizeBaseUrl`.
  - Supports root-relative embedded mount paths while strictly rejecting path traversal,
    dot-segments, and invalid URI schemes.
- **`apps/dsh/src/host.ts` & `apps/dsh/README.md`**:
  - Set `api` parameter to the root-relative path `directorySegment(canonical)`.
  - In proxy forwarding, restored `origin: req.headers.origin ?? origin` to maintain
    loopback ticket binding even after carrier Origin stripping.
  - Hardened origin checks to reject `null` (opaque/sandboxed) origins and
    unsolicited `sec-fetch-site: cross-site` requests.
- **Tests**:
  - Added loopback exchange and multi-origin probe tests in `packages/host/test/auth.test.ts`.
  - Added unit test suite `packages/host/test/base-url.test.ts`.
  - Added end-to-end embedded proxy test `packages/host/test/dsh-plugin.test.ts`.
- **Release & Bump**:
  - Bumped `apps/dsh/package.json` version to `0.1.2`.
  - Rebuilt dsh bundle with `yarn build:dsh`.
  - Tagged `plugin-v0.1.2` for trusted-publishing release via `.github/workflows/dsh-plugin.yml`.
